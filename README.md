# Astrostats

This repository contains an exercise notebook (with and without solutions) used for the April 2026 PhD course in 
Astrostatistics at the University of Rome Tor Vergata. The notebook illustrates  
frequentist and bayesian inference methods, model selection, and fisher-matrix 
forecasts, using the [Supernova Cosmology Project (SCP)](https://supernova.lbl.gov/union/) data as a case study.
